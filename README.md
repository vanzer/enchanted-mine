# Enchanted Mine

Шейдерпак для **Minecraft Java 1.21.1** с **Iris + Sodium**: отражения воды, мягкое свечение, туман и процедурный рельеф текстур. Дополнительный ресурс-пак не требуется. Лицензия — [MIT](LICENSE).

## Что умеет

- Вода с волнами, прозрачностью, поглощением света и экранными отражениями (SSR). Отражения работают над водой и под ней, включая полное внутреннее отражение. Гладкие блоки тоже отражают сцену.
- Bloom от выделенных светящихся материалов: лавы, светокамня, фонарей и других блоков из `shaders/block.properties`. У ламп, свечей и костров учитывается состояние горения.
- Дальний туман в последнем чанке перед границей прорисовки; цвет зависит от биома, времени суток и погоды. Для воды, лавы и рыхлого снега предусмотрено отдельное поглощение.
- Размытие при движении камеры с исключением предметов в руках и отключением при телепортации.
- Процедурный рельеф из яркости текстур, локальное затенение и SSAO, тёплый свет от предмета в любой руке, HDR и тональная коррекция.

## Установка

1. Установите [Iris](https://www.irisshaders.dev/) и совместимый [Sodium](https://modrinth.com/mod/sodium) для Minecraft Java 1.21.1. Один Sodium шейдерпаки не загружает.
2. Соберите готовый архив из корня репозитория. Нужен Python 3.10+; сторонние Python-библиотеки для сборки не нужны:

   ```sh
   python3 tools/package.py
   ```

   В Windows можно использовать `py -3 tools/package.py`.
3. Скопируйте **`dist/EnchantedMine.zip`** в папку `shaderpacks` нужной установки Minecraft. Распаковывать ZIP не нужно. Папку можно открыть из меню шейдеров Iris.
4. Выберите EnchantedMine в Iris. В корне архива должна находиться папка `shaders/`.

Готовый `dist/EnchantedMine.zip` хранится в репозитории. После изменения шейдеров, README или лицензии пересоберите его указанной командой. ZIP содержит шейдеры, README и лицензию; скрипты разработки в него не входят.

## Настройки

Откройте настройки шейдерпака в Iris. Профили LOW / MEDIUM / HIGH меняют качество отражений и силу эффектов.

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| `REFLECTION_STEPS` | Число шагов SSR: 16 / 32 / 64; больше шагов — выше нагрузка | 32 |
| `REFLECTION_STRENGTH` | Сила отражений | 0.8 |
| `HAND_LIGHT` | Сила света от предмета в руках; `0.0` отключает | 1.0 |
| `EXPOSURE` | Экспозиция | 1.0 |
| `BLOOM_STRENGTH` | Свечение; `0.0` отключает | 0.65 |
| `MOTION_BLUR` | Размытие движения камеры; `0.0` отключает | 0.5 |
| `TEXTURE_DEPTH` | Процедурный рельеф и затенение текстур; `0.0` отключает | 0.65 |
| `AO_STRENGTH` | Контактное затенение SSAO; `0.0` отключает | 0.45 |

## Совместимость и ограничения

Целевая версия — Minecraft Java 1.21.1. В предыдущем README была описана проверка с Fabric Loader 0.16.14, Iris 1.8.7, Sodium 0.6.9 и Java 21 на Mesa llvmpipe. При текущей подготовке к публикации запуск Minecraft заново не проводился; повторно выполнены автоматические OpenGL-тесты. Другие версии игры и производительность на NVIDIA/AMD/Intel отдельно не подтверждены.

SSR отражает только доступную в экранных буферах геометрию. Для объектов вне экрана и за камерой используется приближённый цвет окружения. Процедурный рельеф не меняет геометрию и силуэт блоков; LabPBR, настоящий параллакс и динамические солнечные тени не реализованы. Размытие учитывает движение камеры, без отдельных скоростей мобов. Свет от брошенных предметов требует отдельного мода динамического освещения. Дальний туман не скрывает временные дыры загрузки рядом с игроком.

## Разработка и проверки

Структура: `shaders/` — готовые программы GLSL 1.20 и настройки Iris; `shaders/lib/` — общие эффекты; `tools/` — упаковщик и тесты; `.github/workflows/check.yml` — проверки при push и pull request.

Проверка безопасности упаковки работает без дополнительных зависимостей:

```sh
python3 -m unittest discover -s tools -p 'test_*.py' -v
python3 tools/package.py
```

Для OpenGL-тестов используйте Python 3.12 и отдельное окружение:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r tools/test-requirements.txt
.venv/bin/python tools/smoke_test.py
```

В Windows замените `.venv/bin/python` на `.venv\Scripts\python.exe`. Для выполнения нужен рабочий EGL/OpenGL; в Linux без GPU подходит Mesa llvmpipe (`libegl1`, `libgl1`, `libgl1-mesa-dri`). Для установки ZIP игрокам не нужны Python и тестовая среда; игра использует обычный графический драйвер.

Тесты компилируют и связывают все **14 программ** при **16/32/64** шагах SSR, выполняют проходы и читают результат рендера. Проверяются туман, bloom, движение камеры, исключение рук, телепортация и отражение дна под водой. Отдельные тесты упаковки проверяют символические ссылки, скрытые файлы, выход `#include` за корень, циклы и сохранение предыдущего ZIP при ошибке. Сборка воспроизводима в одной среде при неизменных исходниках.

Результаты аудита: [проверка перед публикацией](https://github.com/vanzer/enchanted-mine/blob/main/docs/PUBLICATION_REVIEW.md). Сообщения об уязвимостях: [SECURITY.md](https://github.com/vanzer/enchanted-mine/blob/main/SECURITY.md). Эти документы находятся в репозитории; в игровой ZIP входят README и лицензия.

## Проверка в Minecraft

Проверьте воду над светлым дном и у построек сверху, с уровня поверхности и снизу. На дальности 4/8/16 чанков проверьте туман и переход между биомами. Сравните светокамень с белым бетоном, включённую и выключенную лампы. Проверьте рельеф камня с `TEXTURE_DEPTH=0.0` и `0.65`, движение камеры, резкость предметов в обеих руках, небо, сущности, частицы и интерфейс. После загрузки и перезагрузки пака проверьте журнал Iris на ошибки и FPS на своём GPU.

Для отчёта об ошибке укажите версии Minecraft, Iris и Sodium, видеокарту и драйвер, настройки пака и шаги воспроизведения. Перед приложением журнала удалите личные данные и токены.
