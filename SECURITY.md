# Безопасность

Проверяется актуальная версия Enchanted Mine из `main`. Для старых копий и изменённых сторонними авторами сборок исправления отдельно не выпускаются.

## Сообщить об уязвимости

Если в GitHub включён Private Vulnerability Reporting, используйте **Security → Report a vulnerability**. Если приватный канал недоступен, создайте issue с просьбой предоставить контакт для сообщения об уязвимости, без секретов и подробностей эксплуатации. Не публикуйте ключи, токены или чужие файлы в issue и логах.

Укажите версию или коммит, затронутый файл, возможное последствие и минимальный пример с вымышленными данными. Срок ответа заранее не гарантируется.

## Границы проверки

Игровой ZIP содержит GLSL, настройки и документацию. Python-скрипты и тестовые библиотеки предназначены для разработки и не входят в шейдерпак. В исходниках пака нет сетевых запросов или телеметрии.

Упаковщик принимает только разрешённые типы файлов шейдеров, отказывается от скрытых файлов и символических ссылок, проверяет пути include и заменяет ZIP после успешной записи. Он предназначен для локального доверенного рабочего дерева, без параллельной подмены файлов другим процессом. Расширение `.glsl` само по себе не гарантирует отсутствие случайно записанного секрета: перед публикацией нужно просматривать изменения и историю Git.

Тестовые зависимости закреплены точными версиями и SHA-256 в `tools/test-requirements.txt`; устанавливайте их с `--require-hashes` в отдельное окружение. Новые версии следует обновлять вместе с хешами, аудитом зависимостей и OpenGL-тестами.

Обнаруженные и исправленные проблемы, результаты и ограничения последней проверки перечислены в [отчёте](docs/PUBLICATION_REVIEW.md).
