# Проверка перед публикацией

Дата: 6 ноября 2026 года (Europe/Kyiv).

## Вывод

После исправлений в проверенном локальном дереве не обнаружено блокирующих проблем безопасности для открытия исходников. Добавлены MIT-лицензия, инструкции установки, политика безопасности и автоматические проверки. Репозиторий GitHub на момент проверки приватный; видимость не менялась. Подготовленные изменения ещё нужно сохранить в Git и отправить на GitHub, чтобы они вошли в публикуемую версию. Проверка workflow на самом GitHub пока не выполнена.

Готовый шейдер взят из уже существующей версии `origin/main` (`df24d6d`), вместо старого локального прототипа. Аудит включает отдельную независимую проверку агентом-программистом.

## Найдено и исправлено

| Приоритет | Проблема | Исправление |
| --- | --- | --- |
| Средний | Упаковщик включал любые файлы из `shaders/`, в том числе `.env`, и читал внешние файлы через символические ссылки | Разрешённые расширения, запрет скрытых файлов и ссылок в исходниках, документации и путях назначения; регрессионные тесты |
| Низкий | Тестовый препроцессор не ограничивал пути `#include`, циклы и суммарное разрастание include | Общий валидатор путей и циклов для тестов и сборки; предел 4096 раскрытий и 4 MiB исходников на программу |
| Надёжность | Ошибка записи могла повредить существующий ZIP; временные метки делали сборки различными | Временный файл и атомарная замена; фиксированные метки и порядок файлов |
| Воспроизводимость | Тестовые зависимости задавались диапазонами | Закреплены четыре зависимости, включая транзитивную, с SHA-256 дистрибутивов |
| Документация | Не было лицензии; историческая игровая проверка могла выглядеть как новая | MIT выбрана владельцем; README разделяет историческую проверку и текущие результаты |

## Выполненные проверки

- Просмотр исходников GLSL, настроек, Python-утилит, зависимостей и состава архива. Сетевых запросов, телеметрии, shell-команд, `eval` и опасной десериализации в коде пака и утилитах не обнаружено.
- Поиск распространённых сигнатур секретов в рабочем дереве и 33 уникальных blob доступной истории Git: совпадений не найдено. Проверка не доказывает отсутствия всех возможных секретов; удалённые и недоступные объекты не проверялись.
- `pip-audit`: для `moderngl 5.13.0`, `numpy 2.5.4`, `PyOpenGL 3.1.10`, `glcontext 3.1.0` известных уязвимостей не найдено на дату проверки. Эти библиотеки используются только в тестах.
- 13 регрессионных тестов упаковки: структура и содержимое ZIP, повторяемость, скрытые и посторонние файлы, ссылки на файлы и каталоги, ссылки в путях назначения, непарные программы, выход include за корень, циклы, бюджеты раскрытия include и отказ записи.
- Синтетический OpenGL-тест: все 14 программ компилируются и связываются при 16/32/64 шагах SSR. Проверки рендера тумана, bloom, движения камеры и отражений воды проходят.
- Среда OpenGL: Python 3.12, Mesa 25.0.7, OpenGL 4.5 Compatibility Profile, llvmpipe (LLVM 19.1.7).
- Workflow использует разрешение `contents: read`, checkout по SHA и отключённое сохранение Git-учётных данных. Выполняет тесты упаковки, OpenGL-тесты и сборку на Ubuntu 24.04; тестовые зависимости устанавливаются с проверкой хешей.

## Ограничения и дальнейшая проверка

Minecraft/Iris в рамках этой подготовки заново не запускался. Упоминание прошлой проверки Minecraft 1.21.1 в README взято из предыдущей версии документа; оно не является независимым результатом текущего аудита. Перед объявлением стабильного игрового релиза желательно выполнить сценарии из README на реальном GPU и записать версии драйверов и FPS.

Настройки GitHub branch protection, secret scanning, push protection и приватного приёма уязвимостей отдельно не подтверждены. При открытии репозитория стоит включить доступные проверки секретов и приватный приём сообщений, а после отправки изменений — убедиться в успешном GitHub Actions.

Сборка рассчитана на доверенное локальное дерево без конкурентной подмены файлов. Аудит не охватывает уязвимости Minecraft, Iris, Sodium, Python, OpenGL-драйверов и операционной системы. Отсутствие известных уязвимостей в зависимости не является гарантией её безопасности.
